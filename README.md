# GAPer Guide

GAPer Guide (GG) is an in-game class helper for WoW focused on leveling, talents, macros, rotations and practical gameplay guidance.

## Features

- Level-aware class guidance
- Talent recommendations
- Macro tools
- Action bar setup help
- Solo and dungeon instructions
- Emergency and survival tips
- RU / EN interface
- Minimap GG button
- Multi-class support

## Current status

Paladin support is under active development.
Hunter support is in progress.
More classes will be added step by step.

## Updates

Use CurseForge for normal addon updates.

GitHub Releases are also available for manual installation and development builds.
